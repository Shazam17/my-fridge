# Локальная LLM для справки по продуктам

Справка по предметам на устройстве: модель работает офлайн, данные не уходят в сеть.

## Требования

| ID | Требование |
|---|---|
| FR-L1 | Справка отвечает на вопрос пользователя с учётом его предметов (названия, количество, статус, срок годности, пометка «первым»). |
| FR-L2 | Модель скачивается по запросу (~490 МБ) в `filesDir`, в APK не входит. Прерванная загрузка не считается готовой моделью. |
| FR-L3 | Ответ выводится потоком по мере генерации. Многобайтовый UTF-8 не режется на границе токенов. |
| FR-L4 | Генерацию можно остановить. При закрытии экрана генерация останавливается. |
| FR-L5 | Ответ помечается как подсказка, которая может быть неточной. Лекарства и сроки годности: отсылка к упаковке и врачу. |

## Компоненты

- `third_party/llama.cpp` — исходники llama.cpp (скопированы, без `.git`).
- `app/src/main/cpp/CMakeLists.txt` — сборка библиотеки `localllm` для `arm64-v8a` (NDK 30, CMake 4.1.2).
- `app/src/main/cpp/llm_jni.cpp` — JNI-мост: загрузка модели, шаблон чата, сэмплер (top-k 40, top-p 0.9, temp 0.6), колбэк токенов как байтов.
- `ai/LocalLlm.kt` — Kotlin-обёртка, сборка UTF-8 (`Utf8Boundary`).
- `ai/ModelDownloader.kt` — загрузка через `HttpURLConnection` во временный файл.
- `ai/AdvicePrompt.kt` — системный промпт и список предметов.
- `ai/AdviceService.kt`, `ai/AdviceViewModel.kt`, `ai/AdviceScreen.kt` — сценарий справки.

Модель: Qwen2.5-0.5B-Instruct, GGUF Q4_K_M (`qwen2.5-0.5b-instruct-q4_k_m.gguf`, 491 400 032 байт).

## Ограничения

- Только `arm64-v8a` (`abiFilters`).
- Контекст создаётся на каждый запрос, модель остаётся в памяти до выхода из процесса.
- Модель 0.5B слабее в фактах и рецептах: ответы нужно воспринимать как подсказку.
- Проверка загрузки — по размеру файла. Контрольная сумма SHA-256 не сверяется.
- Qwen2.5 в Q4_K_M лицензирован Apache-2.0; при публикации приложения укажите это в экране «О приложении».

## Тесты

- `LocalLlmTest`: UTF-8 граница (2- и 4-байтовые символы), промпт со списком предметов и пустой список.
- На устройстве не проверялось: генерация, скорость и правила R8 в release-сборке (`proguard-rules.pro`).
